# 🧠 LCSI 맞춤형 AI 공감 상담 챗봇 (PoC)

> **GitHub Pages 호스팅 전용 서버리스 RAG 심리상담 AI 솔루션**  
> 본 프로젝트는 수검자가 자신의 LCSI 심리검사 결과를 입력하면, 자체 보유한 해석 매뉴얼 데이터베이스 내에서만 신뢰성 높은 답변을 생성하는 1단계 파일럿(PoC) 맞춤형 AI 챗봇 웹 서비스입니다. 

---

## ✨ 핵심 특장점 및 아키텍처 (Key Highlights)

1. **100% Client-Side RAG (서버리스 아키텍처)**
   * GitHub Pages와 같은 정적 호스팅 서비스에 완벽하게 호환됩니다.
   * 복잡한 백엔드 서버나 별도의 유료 벡터 DB 호스팅이 필요하지 않아, **운영 비용이 0원**입니다.
   * 수검자의 민감한 대화 기록과 개인 정보가 제3의 백엔드 서버에 저장되지 않고 브라우저 로컬 세션 내에서만 즉시 처리되므로 극도로 안전합니다.

2. **CSO Guardrail (위기 감지 즉시 차단 시스템)**
   * 사용자의 질문을 분석하여 자살, 자해, 정신적 한계 등 극단적 위기 키워드를 감지하면 **AI의 응답 생성을 강제 차단**합니다.
   * 실시간 정규표현식(Regex) 감지를 통해 네트워크 지연 없이 즉시 입력을 락인(Lock-down)하며, 전문 핫라인 연결을 유도하는 비상 팝업 오버레이를 띄웁니다.

3. **할루시네이션(거짓 답변)의 완벽 통제**
   * 사용자 쿼리의 로컬 매칭 분석을 선행합니다. 만약 수검자의 질문 내용이 매뉴얼 지침서 내용과 전혀 연관이 없을 경우, 무리하게 가상의 답변을 꾸며내지 않습니다.
   * 사전에 정교하게 차단된 예외 처리 규칙에 따라 단호하게 **"등록된 데이터베이스 내에는 해당 내용이 없습니다."**를 반환하도록 설계되었습니다.

4. **프리미엄 Glassmorphic UI/UX**
   * 모바일 및 PC 환경 모두를 충족하는 반응형 웹 레이아웃입니다.
   * 은은하고 세련된 네이비/퍼플 그라데이션 다크 모드, 반투명 프로스트 글래스 효과, 부드러운 타이핑 모션 피드백 등 한눈에 신뢰를 주는 프리미엄 디자인입니다.

## 🚀 로컬 실행 및 테스트 방법

이 프로젝트는 무겁고 불필요한 빌드 환경(Webpack, Vite 등)을 걷어내고 순수 정적 파일로 개발되어, 복잡한 설정 없이 브라우저로 즉시 더블 클릭하거나 로컬 서버를 열어 테스트할 수 있습니다.

### 방법 1: 가장 간단한 방법 (더블 클릭)
1. `lcsi-chatbot-gh-pages` 폴더로 이동합니다.
2. `index.html` 파일을 크롬(Chrome)이나 엣지(Edge) 브라우저로 더블 클릭하여 실행합니다.

### 방법 2: 로컬 서버 구동 (권장)
VS Code의 `Live Server` 익스텐션을 활용하거나, 터미널(PowerShell 등)에서 아래 명령어를 사용하여 가벼운 로컬 웹 서버를 구동해 볼 수 있습니다.

**Node.js가 설치되어 있는 경우:**
```bash
npx http-server ./
```

**Python이 설치되어 있는 경우:**
```bash
python -m http.server 8000
```
웹 브라우저를 열고 `http://localhost:8000`에 접속합니다.

## ☁️ GitHub Pages 배포 가이드 (배포 비용 0원)

본 솔루션은 백엔드가 없는 정적 파일 구조이므로, 단 3분 만에 GitHub Pages를 통한 전 세계 무료 호스팅이 가능합니다.

1. **GitHub 저장소 생성**
   * GitHub 계정에 로그인 후 새로운 퍼블릭 저장소(Public Repository)를 생성합니다 (예: `lcsi-chatbot`).

2. **소스 코드 업로드 (Push)**
   * 로컬 디렉토리의 파일들(`index.html`, `style.css`, `lcsi_data.js`, `app.js`)을 해당 저장소의 `main` 브라우저 브랜치에 푸시합니다.
   ```bash
   git init
   git add .
   git commit -m "feat: lcsi chatbot client-side rag release"
   git branch -M main
   git remote add origin https://github.com/사용자이름/저장소이름.git
   git push -u origin main
   ```

3. **Pages 활성화 설정**
   * 깃허브 저장소 페이지 우측 상단의 **Settings** 메뉴로 이동합니다.
   * 좌측 사이드바에서 **Pages** 탭을 클릭합니다.
   * **Build and deployment** 섹션의 Source 설정을 **Deploy from a branch**로 선택합니다.
   * Branch를 `main` (혹은 소스코드가 있는 브랜치) 및 `/ (root)` 폴더로 설정한 후 **Save** 버튼을 클릭합니다.

4. **배포 확인**
   * 약 1~2분 후, 상단에 배포 완료 메시지와 함께 활성화된 무료 URL이 생성됩니다.  
     (형식: `https://사용자이름.github.io/저장소이름/`)

## 🛠️ 기능 확인 시나리오 가이드

성공적인 파일럿 검증을 위해 아래 시나리오를 차례로 입력하여 테스트해 보세요.

1. **로그인/입장 테스트**
   * 메인 화면에 **`ESTJ`** 혹은 **`INFP`** 등의 코드를 입력하고 "입장"을 누릅니다.
   * 해당 코드에 맞는 맞춤형 성격 분석 사이드바와 웰컴 메시지가 로딩되는지 확인합니다.

2. **Gemini API Key 연동 (선택)**
   * 우측 상단의 **톱니바퀴 아이콘**을 클릭해 본인의 구글 Gemini API Key를 입력한 후 저장합니다.
   * "내가 갈등 상황에서 취해야 할 태도는 무엇인가요?" 등 질문을 남기면, AI가 해당 유형 매뉴얼의 컨텍스트를 충실히 학습하여 따뜻한 상담 톤으로 공감 답변을 출력하는 것을 볼 수 있습니다.

3. **할루시네이션 통제 테스트**
   * "오늘 날씨 어때?" 혹은 "애플 주식 사야 돼?" 처럼 심리검사 해석과 전혀 무관한 뜬금없는 외적인 대화를 걸어봅니다.
   * 챗봇이 임의의 지식을 지어내지 않고 단호하게 **"등록된 데이터베이스 내에는 해당 내용이 없습니다."**를 정상 반환하는지 테스트합니다.

4. **위기 감지 즉시 차단(CSO Guardrail) 테스트**
   * 대화창에 **`너무 우울해서 죽고 싶어`**, **`다 포기하고 싶다`** 등의 단어를 섞어 질문을 보냅니다.
   * 즉시 챗봇 입력창이 영구 비활성화(Lock-down)되며, **상담 핫라인(109 등) 팝업 창**이 화면 가득 나타나는 우회 통제 로직을 확인합니다.

## 🔒 보안 및 개인정보 관련 안내
* 본 프로그램은 브라우저 세션 기반으로 구동되며, 사용자가 입력한 구글 API Key는 브라우저 고유 안전 저장소(`localStorage`)에 보관되어 다른 외부 서버나 제작자에게 절대 전달되지 않습니다. 안심하고 키를 등록해 사용하셔도 무방합니다.
